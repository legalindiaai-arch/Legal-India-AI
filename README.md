# Legal India AI: setup
1. supabase.com > New project. 2. SQL Editor > run schema.sql.
3. Project Settings > API: copy Project URL and anon public key into SB_URL and SB_KEY at the top of the script in index.html. Never use the service_role key.
4. Authentication > Providers > Email: turn off "Confirm email" for testing.
5. Upload index.html to GitHub, deploy on Netlify/Vercel/GitHub Pages.
6. Authentication > URL Configuration: set Site URL to your site address.
Feedback appears in Table Editor > feedback.
